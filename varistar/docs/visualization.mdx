## Interactive plots

`viz.interactive` mirrors the static plotting API with Plotly figures —
useful for docs pages where readers can zoom and hover. `plotly` is
already a core dependency of `varistar`, so no separate install is
needed (the module’s own docstring mentions `pip install varistar[viz]`,
but that extra isn’t currently declared in `pyproject.toml` — worth a
quick fix on the package side, or dropping that line from the
docstring):


```python
from varistar.viz.interactive import plot_phased

lc = LightCurve(ts)
lc.run_ls()
plot_phased(lc, period=lc.periods[0])
```
